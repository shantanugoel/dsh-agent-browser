# dsh-agent-browser-pi

[pi](https://pi.dev) extension exposing the same nine browser tools as
[dsh-agent-browser](https://www.npmjs.com/package/dsh-agent-browser)
(`browser_open/snapshot/find/act/get/eval/screenshot/tabs/session`) on top of
[dsh-agent-browser-core](https://www.npmjs.com/package/dsh-agent-browser-core).

```bash
pi install npm:dsh-agent-browser-pi
```
